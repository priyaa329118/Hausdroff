# Caputo–Hausdorff Anisotropic Diffusion for Image Denoising

## About

This repository contains the MATLAB implementation of a fractional PDE-based anisotropic diffusion model for image denoising and restoration.

The proposed framework integrates the Caputo time-fractional derivative and Hausdorff fractal derivative to reduce noise while preserving important image structures and edge information.

## Features

- Caputo fractional derivative using the L1 scheme.
- Hausdorff fractal derivative.
- Gaussian smoothing.
- Edge-preserving anisotropic diffusion.
- Fidelity regularization.

## Requirements

- MATLAB
- Image Processing Toolbox

## Implementation

The MATLAB code implements the proposed image denoising framework. Users can specify the input image, noise level, fractional orders, and other model parameters.

## Performance Evaluation

The restoration performance is evaluated using:

- Peak Signal-to-Noise Ratio (PSNR)
- Structural Similarity Index (SSIM)
- Entropy
- Computational Time
